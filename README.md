# EduTrack

Sistema de gestión y seguimiento educativo.

## Estructura del proyecto

- edutrack2-app: Frontend desarrollado con Angular e Ionic.
- edutrack2-api: Backend desarrollado con Node.js y Express.

## Tecnologías utilizadas

- Node.js
- Angular
- Ionic
- Git
- Docker Desktop
- Visual Studio Code
